Aether Term

BBS terminal client — connect to amateur radio BBS systems over the open-source Aether HF modem, VARA HF, VARA FM, and Soundmodem.
Formerly VARA Term.
By KK4ODA

One-Command Install

Open PowerShell and paste this command:

PowerShell (right-click to paste)
irm https://raw.githubusercontent.com/KK4ODA/aether-term/main/setup_term.bat -OutFile $env:TEMP\setup_term.bat; & $env:TEMP\setup_term.bat
— or —
Download setup_term.bat directly

What the installer does

1
Checks for Git and Python — if either is missing, offers to install automatically via winget (Windows 10/11).
2
Clones the repository — downloads the latest Aether Term source code from GitHub.
3
Installs dependencies — PyQt6, cryptography, pyserial (one-time).
4
Creates a desktop shortcut — double-click "AETHER TERM" to launch. Updates are checked automatically on every startup.

Features

  • Aether HF modem support: live status, rules and fault checks before every call
  • VARA FM and VARA HF modem support
  • Soundmodem / AGWPE packet radio transport
  • HMAC-SHA256 secure authentication (password never sent over RF)
  • Encrypted Winlink registration (WLREG)
  • HF PTT through OmniRig, Hamlib or FLrig
  • Connection profiles and macro buttons
  • Real-time S/N graph
  • Auto-update from GitHub on startup
  • Dark theme terminal display
Requirements: Windows 10 or later. Git and Python 3.10+ are installed automatically if missing.

After install: Configure your callsign in Settings > Terminal Setup, enter the target BBS callsign, and click Connect.

Aether HF: install it from its releases page, turn on Host programs in its Setup step 5, and pick Aether HF in Aether Term's toolbar. Aether HF talks only to other Aether HF stations on the air.

Upgrading from VARA Term: your settings and saved passwords are carried over automatically on first start.
